# INVIT Project AI Instructions — Multi-Model Compliance

**SSOT (Single Source of Truth):** [CLAUDE.md](./CLAUDE.md) — All changes must respect this document.

## 🔒 IMMUTABLE SYSTEM LOCKS (Never Override)

### Lock 1: AI Call Path — Edge Function Only
- ✅ **Allowed:** All LLM calls MUST route through Supabase Edge Functions (`generate-coaching`, `check-fomo`, `submit-bias-assessment`).
- ❌ **Forbidden:** Direct OpenAI API, KRX API, or `service_role` calls from React Native app.
- **Verification:** `grep -r "openai" ./src` must return 0 results.
- **Violation:** PR immediately rejected.

### Lock 2: Feature Flags (Risk Features Default OFF)
- ✅ **Allowed:** Enable risky features ONLY after Gate validation via `feature_flags` table manual update.
- ❌ **Forbidden:** Deploy risk features (FOMO alerts, subscription, coaching AI, re-diagnostics) in default ON state.
- **Lockbox:** FOMO alerts, AI coaching, subscription retry logic all feature-flagged.

### Lock 3: Data Layer 4-Tier Separation + RLS
| Tier | Tables | RLS Rule |
|------|--------|----------|
| User-owned | `users`, `investment_journals`, `principles`, `emotion_logs` | `auth.uid() = user_id` SELECT/UPDATE |
| System-generated | `bias_assessments`, `discipline_logs`, `fomo_alerts`, `coaching_cards` | `service_role` INSERT only; `auth.uid() = user_id` SELECT |
| Admin-managed | `coaching_knowledge_base`, `archetype_templates` | Block all client writes; Admin only |
| Operational | `ai_call_logs`, `error_logs`, `feature_flags` | Block all client access (Edge Function internal only) |

**Non-Negotiable:** Every new table = `ENABLE ROW LEVEL SECURITY` first. No policies = no deployment.

### Lock 4: Idempotency (Prevent Duplicate Records)
- ✅ **Allowed:** Daily records (`discipline_logs`, `fomo_alerts`, `coaching_cards`) MUST use `UNIQUE(user_id, date) + UPSERT` pattern.
- ❌ **Forbidden:** Insert-only approach → pg_cron retries/restarts = data corruption.

### Lock 5: Cost Guardrails
```
$3.00/month  → alert notification (via ai_call_logs aggregation)
$10.00/month  → HARD BLOCK: generate-coaching returns fixed fallback + feature_flags.coaching_ai = false
```
**Fallback Message (Never modify):**
> "오늘의 원칙을 다시 확인해보세요. 일지를 작성하면 내일 새로운 코칭이 준비됩니다."

**Logging Mandatory:** Every OpenAI call → `ai_call_logs` table (`model`, `input_tokens`, `output_tokens`, `estimated_cost_usd`, `function_name`, `user_id`, `created_at`).

### Lock 6: Investment Advisory Filter (Regulatory Lock)
**Forbidden Content:** "매수 추천", "매도 추천", "목표가", "수익 보장", "~할 것입니다", "~오를 것", "~떨어질 것", predictive price expressions.

**Filter Location:** Edge Function `generate-coaching` post-processing ONLY. Not in client.

**Violation Handling:** Don't save response + return fallback + log `type: 'legal_filter_violation'` to `error_logs`.

**Mandatory Disclaimer (Cannot delete/modify/relocate):**
> [중요 고지사항] 본 진단 결과는 귀하의 투자 행동 패턴에 대한 자기 인식을 돕기 위한 교육적 도구로서, 특정 금융투자상품에 대한 투자 권유, 매수·매도 추천, 또는 투자 적합성 판단을 목적으로 하지 않습니다. 본 서비스는 「자본시장과 금융투자업에 관한 법률」에 따른 투자자문업에 해당하지 않으며, 해당 법률에 따른 등록 투자자문업자의 서비스를 대체하지 않습니다. 진단 결과는 귀하의 행동 경향성을 참고하는 용도로만 사용하시기 바라며, 실제 투자 결정은 귀하 본인의 판단과 책임 하에 이루어져야 합니다. 투자에는 원금 손실의 위험이 있습니다. 본 진단 결과에 기반한 투자 손실에 대하여 (주)글로보더는 법적 책임을 부담하지 않습니다.

### Lock 7: No PII to External Models
- ✅ **Allowed:** Mask/summarize user journal text before passing to model.
- ❌ **Forbidden:** Real name, phone, account number, ticker+ROI combo, email in OpenAI payload.
- **Implementation:** `maskPII()` function in Edge Function before model call.

## 📋 Edge Function Standard (6-Step Pipeline)

All Edge Functions MUST follow this order (no skipping):

```typescript
// Step 1 — Input validation + Rate Limit
const parsed = validateInput(req.body); // Zod schema
await checkRateLimit(userId, functionName); // >10/min = 429

// Step 2 — Legal + PII pre-processing
const safeInput = maskPII(parsed.text);
const filtered = legalPreFilter(safeInput); // block investment advice keywords

// Step 3 — Model call (cost check included)
const monthlyCost = await getMonthlyAICost(userId);
if (monthlyCost > COST_BLOCK_THRESHOLD) return fallbackResponse();
const result = await openai.chat(...);

// Step 4 — Post-processing (legal filter + format fix + schema validation)
const postFiltered = legalPostFilter(result);
const validated = outputSchema.parse(postFiltered); // Zod output validation

// Step 5 — Logging (mandatory)
await supabase.from('ai_call_logs').insert({
  model, input_tokens, output_tokens, estimated_cost_usd,
  function_name, user_id, masked_input: safeInput
});

// Step 6 — DB upsert (Idempotency required)
await supabase.from('coaching_cards').upsert(
  { user_id, date: today(), content: validated },
  { onConflict: 'user_id,date' }
);
```

**Exception:** `submit-bias-assessment` skips Step 3 (no model call).

## 🎯 Bias Assessment Schema — LOCK v1.0

| Q | Bias | Scale | Direction | Flag Threshold |
|---|------|-------|-----------|----------------|
| Q1 | Loss Aversion | 5-point | High=biased↑ | `q1 >= 4` |
| Q2 | FOMO | 5-point | High=biased↑ | `q2 >= 4` |
| Q3 | Overconfidence | 5-point | High=biased↑ | `q3 >= 4` |
| Q4 | Disposition Effect | 3-point forced | 1=max biased | `q4 == 1` |
| Q5 | Herding | 5-point | High=biased↑ | `q5 >= 4` |
| Q6 | Present Bias | 5-point intertemporal | Low=biased↓ (reverse) | `q6 <= 2` |
| Q7 | Confirmation Bias | 5-point | High=biased↑ | `q7 >= 4` |

**5 Archetypes (Priority Order):**
1. `panic_reactor` — High Loss Aversion + High FOMO + High Herding
2. `overconfident_holder` — High Overconfidence + High Confirmation Bias + High Disposition Effect
3. `theme_chaser` — High FOMO + High Herding + High Present Bias
4. `rationalized_biased` — Med Overconfidence + High Confirmation Bias + Med Disposition Effect
5. `shortterm_drifter` — High Present Bias + High Loss Aversion + Low-Med FOMO
6. `mixed` — Fallback

**Re-diagnosis Schedule:**
| Bias Type | Interval |
|-----------|----------|
| FOMO, Herding | +3 months |
| Overconfidence | +6 months |
| Others | +12 months |

## 📊 Discipline Score Formula — LOCK v1.0

```
D = (J × 0.40) + (P × 0.40) + (E × 0.20)
```

- **Journal (40%):** `(completed×50) + (rationale×30) + (bias_check×20)`
- **Principle (40%):** `(entry_rule×40) + (exit_rule×40) + (no_impulse×20)`
- **Emotion (20%) — Inverted-V:** `(1 - |emotion - 3| / 2) × 100`

**Edge Cases:**
| Situation | Action |
|-----------|--------|
| No trades today | `entry_rule=true`, `exit_rule=true` auto |
| `bias_check=null` | `true` auto (no penalty) |
| Emotion unchecked | Return 409, block function |
| No journal entry | D_max = 60 cap |
